This NYC transit dataset contains information on subway line, station
name, station latitude / longitude, routes served, entry, vending,
entrance type, and ADA compliance. The dataset was cleaned using
janitor::clean_names(), and the specific variables were chosen using
select(), and mutate and case_match were used to convert the entry
variable from yes/no to true/false. Overall, the dataset has 1868 rows
and 20 columns, but routes are spread across multiple columns so the
data is not tidy.
